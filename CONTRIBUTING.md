# Contributing

Contributions are welcome! Please follow these guidelines:

## How to Contribute

1. Fork the repository
2. Create a new branch for your feature
3. Make your changes
4. Add tests if applicable
5. Submit a pull request

## Code Style

- Use consistent formatting
- Write clear comments
- Follow language-specific best practices

## Adding New Platforms

If you want to add a new platform:
1. Create a new directory under `platforms/`
2. Add language implementations (PHP, Java, Go recommended)
3. Add a README.md explaining the signature method
4. Include test vectors in the docs if applicable
